# Skill Swap

スキルを教え合い・交換できるWebアプリです(卒業制作)。

## 起動方法

````bash
# 1. 依存パッケージをインストール
npm install

# 2. 環境変数ファイルを作成(値はチームの共有場所で確認)
cp .env.example .env

# 3. 開発サーバーを起動
npm run dev
````

> `.env` は秘密情報を含むため、**絶対にコミットしないでください**。

## ブランチ運用

| ブランチ | 用途 |
| --- | --- |
| `main` | 公開用(展示・デプロイ) |
| `develop` | 開発の統合用 |
| `feature/*` | 機能ごとの作業用 |

### ブランチ名の決め方

`feature/<機能名>` の形式で、英語の小文字とハイフンで書きます。

- `feature/auth-login`
- `feature/member-search`

作業は `develop` から `feature/*` ブランチを切って行います。

## コミットメッセージ

先頭に接頭辞をつけます。

| 接頭辞 | 意味 | 例 |
| --- | --- | --- |
| `feat:` | 新機能 | `feat: ログインフォームを追加` |
| `fix:` | 修正 | `fix: ログイン後の遷移先を修正` |
| `docs:` | 文書 | `docs: READMEに起動方法を追記` |
| `chore:` | その他 | `chore: 依存パッケージを更新` |

## Pull Request(PR)のルール

- 宛先(base)は **`develop`** にします
- レビュー担当者(Reviewer)を **1人以上** つけます
- レビューで承認されてからマージします

## 禁止事項

- `main` と `develop` への **直接push**
- `.env` の **コミット**
